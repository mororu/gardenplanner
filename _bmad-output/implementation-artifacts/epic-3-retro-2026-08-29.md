## Verhaltensprüfung

- **`npm run lint`, ganze Kette, Exit 0.** Darin `smoke` mit **592** Behauptungen gegen eine echte SQLite-Datenbank und `smoke:http` mit **141** Behauptungen gegen den **gebauten Server auf einem freien Port**.
